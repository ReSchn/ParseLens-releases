# ParseLens releases

Installers and update files for **ParseLens**, a Windows tray app that collects Warcraft Logs parse
breakpoints for WoW: Forever and writes them into a companion addon.

- Download the latest `ParseLens_*_x64-setup.exe` from [Releases](../../releases/latest).
- Installed copies update themselves from here (`latest.json`).

The source code is not public.
